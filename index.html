Research

Variance reduction

Hybrid weight windows for time-dependent Monte Carlo

An automatic weight window method for global variance reduction in time-dependent problems. Window centers come from an auxiliary hybrid MC/deterministic low-order second-moment (LOSM) solve, discretized to second order in space and time. Efficiency is measured by figure of merit and relative error against an analytic benchmark.

Hybrid methods

Two-level macro–micro transport methods

The transport solution is split into a deterministic macro component and a Monte Carlo micro component. Current work extends the framework with quasi-Monte Carlo sampling and maximum-entropy closures. This is the core of my dissertation, Hybrid Stochastic–Deterministic Methods Based on Coupled Moment Equations for Linear Transport Problems.

HPC

Domain decomposition at scale

I designed and prototyped MC/DC's domain decomposition algorithm. It removed the memory bottleneck that limited problem size in massively parallel runs and enabled simulations on LLNL supercomputers at up to 512 nodes. I've also applied dynamic mode decomposition to Monte Carlo tallies to predict the flux for weight window generation.
